🐍Portfólio de Projetos em Python

Este repositório contém uma coleção de projetos desenvolvidos em Python com foco em aprendizado prático, lógica de programação, interfaces gráficas e integração com banco de dados.

📌 Sobre o Repositório

Este diretório foi criado para organizar diferentes projetos desenvolvidos durante o aprendizado, incluindo sistemas, jogos e aplicações com consumo de dados.

Cada projeto está separado em sua própria pasta, com estrutura independente e funcional.

📁 Estrutura do Repositório
📦 meu-repositorio
├── 🎮 Show do Milhão (Python Tkinter)
├── 🎓 Sistema Acadêmico - Cruzeiro do Sul (Banco de Dados)
├── 💵 Cotação do Dólar (API)
🚀 Projetos Incluídos
🎮 Show do Milhão (Python)

Jogo de perguntas e respostas inspirado no programa de TV.

Funcionalidades:

Interface gráfica com CustomTkinter
Sistema de pontuação
Timer por pergunta
Ranking de jogadores
Perguntas aleatórias
🎓 Sistema Acadêmico - Cruzeiro do Sul

Sistema de gestão acadêmica com login e perfis de usuário.

Funcionalidades:

Login com autenticação
Perfis: Admin, Professor e Aluno
Banco de dados integrado
Separação de áreas por função
💵 Cotação do Dólar

Sistema simples que consulta o valor do dólar em tempo real.

Funcionalidades:

Consumo de API
Exibição da cotação atual
